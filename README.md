# Great Minds Technology Website

React + Vite multi-page starter website using the Great Minds logo's royal-blue and white theme.

## Run locally
1. Install Node.js (LTS).
2. Open this folder in VS Code.
3. In Terminal run `npm install`.
4. Run `npm run dev` and open the local URL shown.

## Pages
- `/` — Home
- `/about` — About Us
- `/courses` — Courses
- `/careers` — Careers
- `/contact` — Contact

## Folder structure
`src/components/` contains shared Navbar and Footer components. `src/pages/` contains a separate folder for each page; each page has its own JSX and CSS file. `src/assets/` contains the logo.

The contact form is currently a frontend demo and does not send or store submissions. Connect a backend or form service before publishing. Course content is starter copy and should be confirmed before launch.
